# wiki/

The compiled knowledge base for this repo: a collection of `.md` files, cross-linked, organized
by decision/subsystem — the "why", not the "what" (the code already documents that).

Built from `../notes/` (scratch notes you drop as you work) and this repo's own git history, by
`compile-wiki`. You mostly view it — in Obsidian or any markdown viewer — rather than edit it by
hand. Start from `index.md` for the current map of content.
